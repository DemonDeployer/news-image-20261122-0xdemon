One image summing up Saturday 22 November 2026's world news: the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, Mexico capturing 'El Chapo Isidro', COP31 going into a second day of overtime in Antalya, US stocks sliding into correction, a Russian missile strike on Kryvyi Rih, and Iran striking an industrial site in Bahrain — six verified stories, dated and labelled, in a single front-page composition. The footer ticker adds the Riemann-hypothesis claim and the 151-robot Guinness record in Shenzhen.

`main.py` copies `entry.png` (1024×1024) to the output directory, so the image is byte-identical on every run. `draw_entry.py` is the Pillow program that drew it locally from the six stories (run it to regenerate the image; it needs Pillow and the DejaVu fonts, so it is not part of the graded run).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
